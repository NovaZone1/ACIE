# 冻结跨域对照评估（2026-09-14）

## 结论

本轮完成了预注册的 HUI360↔SSUP-A 双向跨域评估，共 2 个方向、4 个方法、5 个随机种子，即 40 次 CPU 训练和测试。**预注册的配对贡献判据未通过**：完整模型相对“相同类别权重、但无配对损失”的消融，在 HUI360→SSUP-A 上提高 0.0194 AP，在 SSUP-A→HUI360 上降低 0.0166 AP。判据事先要求两个方向的差值都为正，因此不能把当前结果写成配对损失具有稳健跨域收益。

得到双向支持的是冻结几何后的行为残差分支。`dual_no_pair` 相对纯几何模型的五种子集成 AP 在两个方向分别提高 0.0175 和 0.0465，按目标测试日期组 bootstrap 的区间都高于零。现阶段论文主张应收缩为“接近几何基础上的行为增量在这两个可用跨域子集上提供额外排序证据”；配对学习保留为未获稳健支持的探索性机制。

2026-09-15 增加的容量匹配机制验证进一步支持该主张：保持双分支容量不变、只在各划分和日期组内置换行为张量后，模型 AP 回到纯几何水平；真实行为对应关系相对置换对照的 AP 在两个方向分别提高 0.0185 和 0.0489，两个 bootstrap 区间下界均高于 0。该实验是查看主结果后增加的机制验证，不属于原始预注册。

四个冻结方法分别为纯几何 `geometry`、冻结几何加行为残差但无类别权重和配对项的 `dual_no_pair`、加类别权重但无配对项的 `weighted_no_pair`，以及类别权重和 `pair_lambda=0.03` 的 `full_selected`。

## 主要结果

“单种子 AP”是五次独立训练的均值±标准差；“集成”先平均五个预测概率，再计算一次指标。预注册判断使用集成 AP 差值。

| 方向 | 方法 | 单种子 AP | 集成 AP | 集成 AUROC |
|---|---|---:|---:|---:|
| HUI360→SSUP-A | geometry | 0.1480±0.0119 | 0.1514 | 0.8682 |
|  | dual_no_pair | 0.1577±0.0194 | **0.1689** | **0.8900** |
|  | weighted_no_pair | 0.1412±0.0296 | 0.1345 | 0.8532 |
|  | full_selected | 0.1496±0.0190 | 0.1538 | 0.8730 |
| SSUP-A→HUI360 | geometry | 0.2825±0.0158 | 0.2847 | 0.7400 |
|  | dual_no_pair | 0.3265±0.0336 | 0.3311 | 0.7703 |
|  | weighted_no_pair | 0.3492±0.0444 | **0.3721** | **0.7934** |
|  | full_selected | 0.3538±0.0535 | 0.3556 | 0.7877 |

| 方向 | 预注册比较 | 集成 AP 差值 | 日期组 bootstrap 95% 区间 |
|---|---|---:|---:|
| HUI360→SSUP-A | dual_no_pair − geometry | +0.0175 | [+0.0014, +0.0282] |
|  | full_selected − dual_no_pair | −0.0151 | [−0.0241, −0.0043] |
|  | full_selected − weighted_no_pair | +0.0194 | [+0.0085, +0.0294] |
| SSUP-A→HUI360 | dual_no_pair − geometry | +0.0465 | [+0.0295, +0.0752] |
|  | full_selected − dual_no_pair | +0.0245 | [−0.0035, +0.0533] |
|  | full_selected − weighted_no_pair | −0.0166 | [−0.0566, +0.0077] |

类别权重的作用也明显依赖方向：在 SSUP-A→HUI360 上有利，在 HUI360→SSUP-A 上不利。完整模型与未加权 `dual_no_pair` 的比较同时混入了类别权重和配对项，因此不能用它单独归因配对；主要配对对照应是 `full_selected − weighted_no_pair`。

## 行为信息对应关系机制验证

为区分行为信息贡献与网络容量效应，后续实验保留 `dual_no_pair` 的完整结构和训练设置，只在 train、val、test 各自的日期组内部无固定点置换行为张量。置换不使用标签，且不改变几何输入。

| 方向 | 纯几何 AP | 置换行为 AP | 真实行为 AP | 真实行为−置换行为 | 95% 区间 |
|---|---:|---:|---:|---:|---:|
| HUI360→SSUP-A | 0.1514 | 0.1504 | 0.1689 | **+0.0185** | **[+0.0064,+0.0272]** |
| SSUP-A→HUI360 | 0.2847 | 0.2822 | 0.3311 | **+0.0489** | **[+0.0319,+0.0857]** |

置换行为相对纯几何的差值分别为 −0.0010 和 −0.0025，区间均跨过 0；十个模型的几何分支输出保持不变。这说明观察到的增益需要正确的行为—样本对应关系。逐日期差值并非全部为正，但删除任一目标日期后的整体差值在两个方向都保持为正，表明总体增益不由单个日期驱动。完整协议与结果见 `reports/behavior_information_control_2026-09-15.md`。这是主结果后的机制验证，不能追溯标记为原始预注册。

## 官方参考模型五种子公平对照

官方 HUI360-Baselines MLP、LSTM 与 ST-GCN 均已按相同冻结窗口和种子 11、22、33、44、55 补充到对照中，全部使用源域验证选模和五种子概率集成。

| 方向 | 官方 MLP AP / AUROC | 官方 LSTM AP / AUROC | 官方 ST-GCN AP / AUROC | ACIE 最佳 AP（方法） | ACIE 最佳 AUROC（方法） |
|---|---:|---:|---:|---:|---:|
| HUI360→SSUP-A | 0.0932 / 0.7296 | 0.1340 / 0.7878 | 0.0416 / 0.5650 | **0.1689**（dual_no_pair） | **0.8900**（dual_no_pair） |
| SSUP-A→HUI360 | 0.4264 / 0.7449 | 0.4124 / 0.7734 | **0.4609** / 0.7269 | 0.3721（weighted_no_pair） | **0.7934**（weighted_no_pair） |

ST-GCN 的前向 AP 显著低于 MLP、LSTM 和四个 ACIE 变体，所有日期组 bootstrap 区间均低于 0；反向 AP 点估计最高，但与各对照的区间全部跨过 0，且 AUROC 低于多数模型。三种官方架构都表现出不同程度的方向依赖，ST-GCN 最明显。完整结果见 `reports/official_fair_stgcn_comparison_2026-09-14.md`、`reports/official_fair_lstm_comparison_2026-09-14.md` 与 `reports/official_fair_mlp_comparison_2026-09-14.md`。

## 收敛范围补充诊断与强简单基线

E3 已直接汇总 40 份冻结测试指标。`dual_no_pair` 在 HUI360→SSUP-A 和 SSUP-A→HUI360 上的局部最终排序准确率相对自身几何分支分别变化 +0.0175±0.0422 和 +0.0054±0.0242。该诊断方差较大，只用于刻画接近条件下的局部排序，不作为配对贡献证据；完整表见 `reports/e3_pair_diagnostic_2026-09-15.md`。

后续冻结的 post-hoc 补充对照还运行了同结构 `random_pair`、HistGradientBoosting 和 Random Forest，各两个方向、五个种子。正确几何配对相对随机配对只在前向提高 AP，反向差值区间跨 0，继续不支持双向配对损失主张。HistGB 的五种子集成 AP 在前向为 0.1318、反向为 0.4712；其反向点估计高于当前 ACIE 与官方参考模型，前向则低于 `dual_no_pair`。因此结果不能表述为 ACIE 全面优于强简单基线。完整协议、区间和时间统计见 `reports/revised_scope_controls_2026-09-15.md`。

## 证据边界

冻结数据 revision 与官方配置存在三个可核查的不一致名称：HUI360 训练配置中的 `rosbag2_2025_07_10-10_29_13` 缺失，SSUP-A 测试配置中的 `2023_07_11_albee_square_landfill_0` 和 `2023_07_12_albee_square_landfill_1` 缺失。因此 HUI360→SSUP-A 的源域和目标域都属于**可用官方配置子集**，不能标成完整官方 benchmark；SSUP-A→HUI360 使用的 SSUP-A 训练池和 HUI360 测试池在相应配置下完整可用。

目标测试只有 5 个和 9 个日期组，百分位 bootstrap 区间可能不稳定。结果支持当前数据和冻结协议下的模型排序，不代表真实机器人安全收益或人的内部心理状态。上表补充的官方参考模型使用相同可用子集，但仍不能称为完整官方 benchmark。
